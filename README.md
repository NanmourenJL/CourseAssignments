# 🎓 Undergraduate Projects @ Yanshan University

本仓库用于整理和记录我在 **燕山大学本科阶段（测控技术与仪器专业）** 学习期间完成的课程设计、实验项目、工程实践及个人探索项目。
内容涵盖 **自动化、测控技术、嵌入式系统、信号处理、仿真分析、机器学习** 等方向。

这些项目记录了我从基础课程学习，到软硬件系统设计，再到科研探索的学习过程，也作为本科阶段工程实践经历的总结与归档。
